# Code2.js

Тут лежат модули которые я вынес из Code.js чтобы не раздувать основной файл.

Грузится после Code.js — если Code.js не готов, сразу останавливается с ошибкой.

## Что здесь:

- **Player Info** — отслеживает ник, ID, скин, сервер игрока.
- **Dialog Monitor v2** — перехватывает серверные диалоги игры и отправляет в Telegram.
- **Завод** — авто-производство. `/zon` включить, `/zoff` выключить. Сам нажимает кнопку начать производство и заполняет токарный станок (Turner).
