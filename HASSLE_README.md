# VirtualDisplay + Hassle (форк с плавающими окнами)

Это проект Ynkcc/VirtualDisplay с добавками под Hassle: игры идут на виртуальных дисплеях,
а каждый дисплей показывается **плавающим окном поверх всех приложений** на самом телефоне.
Окна рисует само приложение (оверлеи), поэтому лимит MIUI «не больше двух плавающих окон» на них не действует.
ПК и scrcpy не нужны.

## Что добавлено
- Вкладка **Hassle**: галочки Hassle 1-6, ширина/высота/DPI (по умолчанию 1280x720/240), пауза между запусками.
- Кнопки: «Запустить выбранные», «Показать окна заново», «Убрать окна», «Остановить всё».
- Для каждого окна: перетаскивание за заголовок, изменение размера (квадрат справа внизу, пропорции дисплея
  сохраняются, окно не выходит за экран), кнопка «ТАЧ» (вкл/выкл передачу касаний в игру),
  «🔊/🔇» (выключить/включить звук этой игры), «↻» (перезапуск игры: нажать два раза подряд в течение пары секунд),
  «—» (свернуть: игра идёт, картинка не рисуется), «✕» (убрать окно).
  Звук выключается через appops PLAY_AUDIO для пакета игры, состояние сохраняется системой.
- Те же настройки фона, что в ПК-меню (whitelist батареи, RUN_IN_BACKGROUND, standby bucket, phantom processes).
  Выполняются через Shizuku при запуске.
- Приложение само выдаёт себе «Поверх других окон» через Shizuku (appops). Если не вышло, откроет настройки.
- Новый метод `runShell` в сервисе Shizuku (AIDL), foreground-сервис `OverlayService`.
- Сборка в GitHub Actions без секретов (debug APK) и без сабмодулей (scrcpy подтягивается сам).

Окно «Убрать» не останавливает игру: дисплей остаётся и работает в фоне. «Остановить всё» закрывает игры и удаляет дисплеи.

## Сборка без Android Studio (GitHub Actions)
1. Создайте на GitHub пустой репозиторий и загрузите в него содержимое этой папки (включая `.github`).
2. Вкладка **Actions** -> **Build debug APK** -> дождитесь зелёной галочки (или Run workflow).
3. Внутри запуска, раздел Artifacts, скачайте `app-debug-apk`, распакуйте, установите APK на телефон.

## Сборка в Android Studio
1. Склонируйте scrcpy в папку `scrcpy` рядом с `app`:
   `git clone https://github.com/Genymobile/scrcpy.git scrcpy` и `git -C scrcpy checkout 3fcc177da5b6b4514d0e8e8d90d7d58d6731eac9`
2. Откройте проект, Build -> Build APK(s).

## Первый запуск на MIUI 14
1. Установите Shizuku и запустите его через **беспроводную отладку** (не через root, иначе будет ошибка `packageName must match the calling uid`).
2. Включите «Отладка по USB (настройки безопасности)» - без неё касания через shell на Xiaomi часто блокируются.
3. Откройте приложение, выдайте доступ Shizuku, вкладка Hassle, «Запустить выбранные».
4. Если окна не появились: Настройки -> Приложения -> это приложение -> включите «Поверх других окон»,
   «Всплывающие окна в фоновом режиме», батарея «Нет ограничений», автозапуск.
5. После обновления APK один раз нажмите «Force restart service» на вкладке настроек или перезапустите Shizuku
   (в сервис добавлен новый метод, старый процесс должен быть заменён).

## Важно
Код написан без возможности собрать и запустить его на устройстве. Если сборка или запуск упадёт,
пришлите текст ошибки из Actions (или logcat), исправлю.
